# Модель study-bot

Бот — основной интерфейс ежедневной работы. Сайт — план, настройки и аналитика.
Предметы создаются из каталога проектов ФИПИ-2027 или вручную
Задание — отдельная сущность с собственным максимальным баллом
Группы заданий принадлежат предмету и могут пересекаться: связи хранятся в group_tasks
Стандартные группы — тестовая и вторая части, пользовательские группы имеют произвольный состав
При первом запуске новой версии группы создаются из прежнего поля tasks.part
Существующие задания, результаты и идентификаторы сохраняются; дальнейшие изменения состава не сбрасываются
Новое задание может не входить ни в одну группу
Ученик имеет одного учителя; учитель — несколько учеников. Аккаунт может совмещать роли.
Учитель управляет планом, но не результатами. Привязка подтверждается учеником.
Новая цель выбирает существующий предмет и созданную группу либо несколько конкретных заданий
Связь новой цели с группой или выбранными номерами хранится в goal_selections
Для группы можно считать решения её заданий или полные выполнения группы в одном занятии
Старые цели по тестовой/второй части продолжают считаться по прежним правилам
В цель засчитывается попытка независимо от балла. Полная тестовая часть — одна попытка варианта;
выбор отдельных заданий учитывается в аналитике заданий, но не как полный вариант
Если в записи тестовой части есть нерешённые задания, она не считается полной попыткой варианта
Ввод группы начинается с максимальных баллов: отдельно отмечаются нерешённые задания и ошибки
Для ошибок в многобальных заданиях уточняется фактический балл, ошибка в однобальном даёт 0
Нерешённое задание и попытка с нулём баллов различаются
Слоты — ориентир, без штрафов за пропуски. Повторения материализуются в выбранном диапазоне недель.
Редактирование повторений требует выбора области: одна неделя, будущие, весь период.
Пробники отдельно от обычных целей. Каждый результат хранит максимум на момент решения
Пробник можно внести итоговым первичным баллом (exam_totals), списком баллов по заданиям или сеткой выбранных заданий
Запись только с итоговым баллом участвует в графике пробников, но не добавляет вымышленные попытки по заданиям
Исправление такого пробника сохраняет исходный максимум и снимок шкалы
При выборе заданий однобальные сразу получают 1, для многобальных бот спрашивает балл
Черновики сохраняются в базе, кнопки выбора и исключений привязаны к текущему вводу и шагу
Пробники сохраняют вторичный балл на момент внесения; отсутствующая строка шкалы не интерполируется.
Самочувствие и нагрузка необязательны; бот не интерпретирует ответы. Доступ учителя отключаемый.
Вечерний опрос ежедневно, напоминания отключаемые, итоги по воскресеньям.
Тон спокойный, тёплый, без давления и чрезмерной похвалы.
