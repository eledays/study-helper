## Шкала перевода

Официальная шкала перевода первичных баллов в тестовые для ЕГЭ-2027 при проверке не подтверждена
Спецификации ФИПИ не содержат таблиц соответствия
Шкалы 2026 нельзя автоматически выдавать за 2027, особенно при изменившемся максимуме по математике и истории
Готовые предметы создаются без шкалы: первичные баллы рассчитываются, вторичные остаются пустыми
В настройках есть редактор шкалы для ввода утверждённой таблицы
Ранее сохранённые пробники сохраняют снимок своей шкалы

Русский язык и профильная математика добавляются в аккаунт без предметов
Остальные предметы выбираются из каталога в настройках
Повторный выбор не создаёт дублей и не перезаписывает настройки
Существующие пользовательские предметы и задания не меняются
